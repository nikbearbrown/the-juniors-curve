# The Junior's Curve

Research in progress. How is entry-level STEM work changing? This is the early-career slice of [A New Shape for Work](https://github.com/nikbearbrown/a-new-shape-for-work), using the same work-phase framework. The first strand tracks what employers ask of new entrants across technical STEM, not just software. A separate software pilot asks how coding agents affect what first-year developers actually do and learn.

The working hypothesis is that agent access shifts **human active effort** from implementation toward specification and verification. Effects on design, operations, total effort, quality, and durable learning are open empirical questions. Job ads measure stated demand, not hiring, work time, productivity, or learning. The software pilot does not stand in for all STEM work.

## Abstract

*Working abstract. No manuscript exists yet, so this describes what the paper sets out to do. It reports no results.*

How is entry-level STEM work changing as AI tools take on more of it? This study is the early-career slice of *A New Shape for Work* and uses the same six work phases. One strand builds comparable cohorts of entry-level job postings across technical STEM fields and tracks what employers ask of new entrants. A separate software pilot asks how coding agents affect what first-year developers do and learn. The working hypothesis is that access to an agent moves a person's active effort from implementation toward specification and verification. Effects on design, operations, total effort, quality and durable learning are open questions. Job ads measure stated demand, not hiring, working time, productivity or learning, and the software pilot does not stand in for all STEM work.
