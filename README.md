# The Junior's Curve

Research in progress. Did coding agents change what early-career software developers spend time doing, and what that work teaches them?

The working hypothesis is that agent access shifts **human active effort** from implementation toward specification and verification. Effects on design, operations, total effort, quality, and durable learning are open empirical questions. A separate labor-market question asks whether firms changed junior hiring. Job ads measure stated demand, not work time; productivity and learning are separate outcomes.

- `data/illustrative-curve.tsv`: the author's hypothetical phase shares, **not observations or estimates**.
- `methods/phase-measurement.md`: a proposed, not preregistered, pilot.
- `sources.md`: source and data audit.

Do not commit private messages, participant records, source code from employers, or third-party data without checking permissions. No study participants have been recruited and no causal result is claimed.
